# Как участвовать

Спасибо, что хотите улучшить AI Team Kit! Принимаются любые доработки: новые роли, правки процесса, исправления в установщике и скриптах, опечатки, переводы.

## Issue

- **Нашли ошибку** — опишите, что делали, что ожидали и что получилось. Если роль повела себя не так, приложите кусок разговора (без секретов!).
- **Есть идея** — опишите проблему, которую она решает, и как вы её видите.

## Pull request

1. Сделайте fork и ветку от `main`.
2. Внесите изменения. Одна тема — один pull request.
3. Проверьте установщик на пустой папке, если трогали `install.sh`, `claude/`, `team/`, `prompts/` или `tools/`:

   ```bash
   mkdir -p /tmp/kit-test && sh install.sh /tmp/kit-test
   ```

4. Если трогали `tools/session_history.py`:

   ```bash
   python3 -m py_compile tools/session_history.py
   ```

5. Откройте pull request и коротко напишите, что и зачем поменяли.

## Правила для файлов

- Названия файлов и папок — по-английски, содержание — на русском (переводы на другие языки — отдельными файлами, приветствуются).
- Роль меняете — проверьте, что описание в `team/roles/`, навык в `claude/skills/`, `team/PLAYBOOK.md`, `team/TEAM-DIRECTORY.md` и `team/AGENTS-ROSTER.md` не противоречат друг другу.
- Новая роль — по образцу существующих: файл роли, навык, строки в справочнике и реестре.
- В навыках и агентах не должно быть `hooks` и `permissionMode` во frontmatter, а у агентов — инструмента запуска других агентов.
- Никаких реальных ключей, токенов, паролей и личных данных — ни в коде, ни в примерах.
