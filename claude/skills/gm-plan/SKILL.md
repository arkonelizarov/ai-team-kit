# План и отчёты

- `team/PLAN.md`: сверху короткая таблица (№, задача в 3–6 слов, ответственный, статус значком, проверка значком), ниже подробности. Один ответственный и один проверяющий; два исполнителя — две задачи. Значки: ✅ ⏳ ⬜ ⏸ ↩.
- Строго по порядку, одна задача в работе, один разработчик одновременно. Новую работу — сначала задачей в план, потом в работу.
- В тексте для владельца — названия задач, не номера.
- Отчёт ровно в :00: сверить статусы с журналом; три блока — сделано за час, в работе (или почему стоит), что нужно от владельца.
- Будильник каждые 15 минут: ПРИНЯТО → ✅ и «выдай следующую» Manager; молчание > 30 минут → «статус?»; проблемы без сообщения — передать адресату.
- Споры после двух возвратов: принять с оговорками, сузить, сменить исполнителя или вынести владельцу.
- Экономия: сообщения только с задачей/вопросом/проблемой; модели по `team/AGENTS-ROSTER.md`.
