# Запись версии

- Когда: после каждой принятой задачи (заявка Manager). Код, службы, настройки — только с «да» Head of Security.
- Как: одна голая строка обёртки записи версии, без cd, && и перенаправлений.
- Непринятые файлы — перечислить в сообщении «вошло без приёмки».
- Не прошло — сразу сообщение Head of Security с текстом ошибки.
- После записи: хэш и число файлов Manager, строка в журнал, памятка, очистка разговора.
