# Выдача и статусы

- Выдача — одно сообщение исполнителю: номер и название, где подробности, кому сдавать, строка «при проблеме — сразу сообщение по team/TEAM-DIRECTORY.md».
- Перед выдачей разработчику — по журналу проверить, что второй разработчик ничем не занят (включая внеплановые сборки).
- ПРИНЯТО → ✅ в обеих таблицах, строка «Сделано», заявка Releaser, выдача следующей.
- Счёт возвратов в колонке «Прогресс»; третья неудача — спор к General Manager.
- Пауза рассылки: сообщение в `team/outbox/OUTBOX-Manager.md`, будильник отправит.
