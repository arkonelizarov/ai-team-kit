# Рутина DevOps

- Сверка sha256: файл на диске = названный автором; установленное = проверенное Head of Security.
- Команды установки владельцу — только по образцу Head of Security и только после его «ДА»: проверка «не ссылка» и sha каждого файла, затем копирование.
- Бэкап перед любой записью в данные. Корзина — только по списку Head of Security.
- Обёртки запускать одной голой строкой (без cd, &&, перенаправлений).
- Сомнение по безопасности — стоп и сообщение Head of Security.
