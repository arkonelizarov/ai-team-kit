# Приёмка

1. Критерии — из описания задачи (раздел «Приёмка»).
2. Проверяй сам: свои запросы только на чтение, свои случайные выборки (≥10 на правило).
3. Пересчитай ключевые цифры; расхождение больше допуска — дефект.
4. Сохранность: не изменено то, что не должно; бэкап до записи есть; sha кода совпадает.
5. Приватность и секреты: поиск по шаблонам.
6. Повторяемость: пересборка даёт то же.
7. Вердикт: ПРИНЯТО (оговорки списком) / ВОЗВРАТ (дефекты с уровнем С1–С3: что, где, пример, сколько, что сделать) / СПОР после двух возвратов. Файл `team/audits/AUDIT-<дата>-<задача>.md`, строка в журнал, одно сообщение адресату.
