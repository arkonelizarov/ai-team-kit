# Проверка безопасности

Чек-лист диффа: sha256 совпадает; в диффе только заявленное; запуск без наследования окружения; нет симлинков и выхода за проект; точное число аргументов, без glob; файлы-описания читаются один раз атомарно; в логи не пишутся секреты; при ошибке — безопасный стоп.
Агенты и навыки: во frontmatter нет hooks/permissionMode; у агентов нет инструмента запуска агентов; права не шире вызывающего.
Удаление — только в Корзину через обёртку. Права — классом, одной командой владельцу. Вердикт: ДА/НЕТ + дефекты С1–С3 + sha проверенной версии; запись в `team/SECURITY-DECISIONS.md`.
